# G · Governance（治理层）· P6

> 谁能做什么，花多少，风险怎么控。

**优先级：P6** — 权限体系已基本完成，当前规模下治理不是瓶颈。

---

## 当前状态

- 权限角色：admin / editor / viewer 三级，可视化矩阵，已完成
- API Key：用户自管，存于 localStorage，不经过任何服务器
- 无 rate limiting（用户自己承担 API 费用，无需限流）
- 无 token 成本预估
- 无多用户隔离（纯单用户应用）

---

## Gap 分析

当前规模下问题不大，但以下场景值得关注：

| 场景 | 风险 | 优先级 |
|------|------|-------|
| 用户误触大量生成 | API 费用意外超支 | 低 |
| 单次生成 token 过多 | 触发 API 400 错误 | 已修复（max_tokens 保护） |
| 分享链接泄露 API Key | 安全风险 | 中（当前分享链接是否含 key？需确认） |

---

## 方案

### 方案 A：生成前 Token 预估提示

在点击生成前，根据 prompt 长度粗估 token 数和预计费用，显示提示：

```
预计消耗 ~3,000 tokens，约 $0.003（基于 GPT-4o 定价）
```

### 方案 B：每日生成次数软限制

在 localStorage 记录今日生成次数，超过阈值（如 20 次）显示警告，防止误操作循环生成。

### 方案 C：分享链接安全审查

确认分享链接内容不包含 API Key 或其他敏感信息。

---

## 实现难度

- 方案 A（费用预估）：中（需维护各模型定价表）
- 方案 B（次数限制）：低
- 方案 C（安全审查）：低（审查现有实现）
