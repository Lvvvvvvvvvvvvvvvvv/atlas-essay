## 1. 快速入门

### 1.1 首次打开应用

1. 在浏览器地址栏输入部署地址（如 `https://your-username.github.io/your-repo/`）并回车。
2. 应用会自动加载，首次加载约需 1-3 秒。
3. 如未配置 API Key，应用将进入**演示模式**——生成功能仍可点击，但输出固定示例内容（咖啡行业报告），不消耗真实 API 调用。

### 1.2 最小化配置步骤（3 步上手）

**Step 1：添加 AI 模型 Key**

1. 点击左侧边栏底部齿轮图标 ⚙ 打开「设置」。
2. 切换到「模型」标签页。
3. 找到目标模型（如 GPT-4o），在「API Key」输入框中粘贴你的 Key，点击「保存」。

**Step 2：选择模型**

1. 回到主界面，点击左侧边栏顶部的模型选择下拉框。
2. 从列表中选择刚刚配置了 Key 的模型。
3. 模型名称旁出现绿色圆点表示该模型已就绪。

**Step 3：生成第一份报告**

1. 在主界面右侧的输入框中输入报告主题，如「杭州2025年新能源汽车市场分析」。
2. 点击蓝色「生成报告」按钮。
3. 等待约 15-60 秒，报告将实时流式显示在屏幕上。

## 3. 模型配置

### 3.1 内置模型列表

系统预置以下模型（需用户自行提供 API Key）：

| 模型名称 | 提供商 | 特点 |
|----------|--------|------|
| GPT-4o | OpenAI | 综合能力强，推荐首选 |
| GPT-4o mini | OpenAI | 速度快，成本低 |
| GPT-o3 | OpenAI | 推理增强版 |
| Claude 3.5 Sonnet | Anthropic | 长文本优秀 |
| Claude 3.7 Sonnet | Anthropic | 最新旗舰版 |
| Gemini 2.0 Flash | Google | 免费额度大 |
| DeepSeek V3 | DeepSeek | 中文能力强，价格极低 |
| DeepSeek R1 | DeepSeek | 推理链可见 |

### 3.2 配置内置模型 API Key

1. 点击左下角 ⚙ → 「模型」标签。
2. 找到目标内置模型卡片。
3. 在「API Key」一栏点击输入框，粘贴 Key（格式通常为 `sk-xxxx`）。
4. 如需修改 API Base URL（使用中转服务时），展开「高级」填写自定义地址。
5. 点击「保存配置」，右上角出现绿色 Toast 提示「已保存」。
6. Key 以明文存储于浏览器 localStorage，请勿在公共电脑使用。

### 3.3 添加自定义模型

1. 在「模型」标签页点击「+ 添加自定义模型」按钮。
2. 填写以下字段：
   - **模型名称**（显示用，如「Qwen-Max」）
   - **Model ID**（发给 API 的实际 ID，如 `qwen-max`）
   - **API Key**
   - **API Base URL**（如 `https://dashscope.aliyuncs.com/compatible-mode/v1`）
3. 点击「添加」，模型立即出现在选择列表。
4. 自定义模型数据存储于 `atlas_custom_models` localStorage。

### 3.4 删除/移除模型

**移除内置模型（隐藏）**：
1. 在内置模型卡片右上角点击 ✕ 或「移除」按钮。
2. 该模型从选择列表中消失，但 Key 配置不丢失。
3. 如需恢复：点击「恢复默认模型」即可重新显示。

**删除自定义模型**：
1. 找到自定义模型卡片，点击右上角删除图标（🗑）。
2. 弹出确认提示，点击「确认删除」。
3. 自定义模型被永久移除，Key 数据同时清除。

### 3.5 选择当前模型

1. 在左侧边栏顶部点击模型下拉框。
2. 列表显示所有可用模型（内置已配置 Key + 自定义模型）。
3. 点击目标模型即选中，下拉框关闭。
4. 选中模型存储于 `atlas_selected_model` localStorage，刷新后保持。

### 3.6 设置生成参数

在「设置 → 模型」标签页还可配置：

| 参数 | 说明 | 默认值 | 范围 |
|------|------|--------|------|
| Temperature | 创意度（越高越随机） | 0.7 | 0–2 |
| Max Tokens | 单次最大输出长度 | 4096 | 1–131072 |
| System Prompt | 全局角色提示词 | 内置默认 | 任意文本 |

> ⚠ **注意**：Max Tokens 上限已硬性限制为 131072，超大值会自动截断以避免 API 400 错误。

## 4. 报告生成

### 4.1 生成报告（基础流程）

1. 在主界面「首页」视图中，找到右侧「报告主题」输入区域。
2. 在文本框中输入你想要分析的主题，例如：
   - `2025年中国新能源汽车市场竞争格局分析`
   - `杭州师范大学近5年就业率报告`
   - `AI大模型行业现状与未来趋势`
3. （可选）在「补充要求」框中输入特殊要求，如：
   - `请重点分析头部企业市场份额`
   - `结论需包含可行性建议`
4. 点击蓝色「生成报告」按钮。
5. 报告以流式方式逐字输出，实时显示在屏幕上。
6. 全部输出完成后，顶部出现「生成完成」提示，同时提供「保存」「导出」等操作按钮。

### 4.2 停止生成

- 生成过程中，按钮变为红色「停止生成」。
- 点击「停止生成」立即中断输出。
- 中断后已生成内容保留，可选择保存或重新生成。

### 4.3 重新生成

1. 报告生成完成后，点击「重新生成」按钮。
2. 系统使用相同的主题和参数重新调用 API。
3. 旧内容被替换为新输出（注意：未保存的旧内容将丢失）。

### 4.4 演示模式说明

- **触发条件**：所选模型没有配置有效的 API Key。
- **表现**：点击生成后输出固定的咖啡行业示例报告，与输入的主题无关。
- **解决方法**：参见 [3.2 配置内置模型 API Key](#32-配置内置模型-api-key)。
- **标识**：演示模式下页面顶部会出现「演示模式」橙色标签。

### 4.5 配置数据源辅助生成

> 数据源允许你提供参考网址，AI 生成时会优先参考这些来源。

1. 前往「数据源」页面，点击「+ 添加数据源」。
2. 输入网址（如行业报告 PDF 地址、政府统计网站等）。
3. 回到首页，在生成前勾选「使用数据源」开关。
4. 点击生成，AI 会在 Prompt 中附带数据源上下文。

### 4.6 使用模板生成

1. 在首页生成区域点击「选择模板」下拉框。
2. 从预置模板列表中选择（如「行业分析报告」「竞争对手对比」「SWOT分析」）。
3. 选择后输入框自动填充模板结构提示词。
4. 修改主题后点击生成即可。

## 5. 报告查看与编辑

### 5.1 查看已生成报告

**查看当前刚生成的报告**：
- 生成完成后自动显示在主界面右侧区域。

**查看历史保存报告**：
1. 点击左侧「报告库」导航。
2. 在列表中点击任意报告卡片。
3. 报告全文在右侧主区域展开显示。

### 5.2 报告渲染模式

报告内容以 Markdown 格式存储，查看时提供两种渲染模式：

| 模式 | 说明 | 切换方式 |
|------|------|----------|
| 渲染模式 | Markdown 转换为格式化 HTML，支持标题层级、表格、列表等 | 默认 |
| 原始模式 | 显示原始 Markdown 文本，便于复制和编辑 | 点击右上角「原始」按钮 |

### 5.3 保存报告

**方式一：生成后立即保存**
1. 报告生成完成后，点击顶部「保存报告」按钮。
2. 弹出保存对话框，可编辑报告标题（默认使用 AI 提取的主题）。
3. 可选择添加标签（如「行业分析」「内部文档」）。
4. 点击「确认保存」，报告存入 localStorage `atlas_saved_reports`。
5. 右上角出现绿色 Toast「已保存到报告库」。

**方式二：从报告库视图保存**
- 在报告库点击「另存为」可创建当前报告的副本。

### 5.4 收藏报告

1. 在报告库列表中，点击报告卡片右侧的「★」星形图标。
2. 图标变为黄色，该报告被标记为收藏。
3. 点击报告库顶部的「★ 仅显示收藏」筛选按钮可快速找到收藏报告。
4. 再次点击星形图标取消收藏。

### 5.5 报告元数据

每份保存的报告包含以下元数据：

| 字段 | 说明 |
|------|------|
| id | 唯一标识符（UUID） |
| title | 报告标题 |
| content | Markdown 全文 |
| createdAt | 创建时间戳 |
| model | 生成时使用的模型名称 |
| tags | 用户自定义标签数组 |
| isFavorite | 是否收藏（布尔值） |

## 6. 多格式导出

### 6.1 支持的导出格式

| 格式 | 说明 | 需要网络 |
|------|------|----------|
| JSON | 完整元数据备份，可导回 | 否 |
| Markdown (.md) | 纯文本格式，适合开发者 | 否 |
| PDF | 打印友好格式 | 否（浏览器原生） |
| DOCX | Word 文档，适合商务场景 | 是（CDN） |
| Notion | 导出为 Notion API 格式 | 否 |
| 分享链接 | 生成可分享的 URL | 否（本地编码） |

### 6.2 导出单份报告

1. 在报告库或报告查看页面，找到目标报告。
2. 点击报告卡片右侧的「导出」按钮（或三点菜单 → 导出）。
3. 在弹出的格式选择框中，点击所需格式图标。
4. 浏览器自动下载对应格式文件，或跳转至分享链接页面。

### 6.3 批量导出多份报告

**选择要导出的报告**：
1. 进入「报告库」页面。
2. 点击右上角「多选」按钮，进入多选模式。
3. 点击报告卡片左侧出现的复选框，勾选目标报告。
4. 也可点击「全选」一键选中所有报告。

**选择导出格式**：
1. 批量选择后，底部操作栏出现「导出已选 (N)」按钮。
2. 点击该按钮打开导出面板。

**选择合并方式**（JSON 和 MD 格式专属）：

| 选项 | 说明 | 适用场景 |
|------|------|----------|
| 合并为一份 | 所有选中报告合并为单一文件 | 归档、整合阅读 |
| 分别导出 | 每份报告单独生成一个文件 | 分发给不同读者 |

**执行导出**：
1. 选择合并方式后，点击格式按钮（JSON / MD / PDF / DOCX 等）。
2. 对于「分别导出」模式，浏览器会依次触发多次下载。
3. 部分浏览器会询问「允许多次下载」，选择「允许」。

### 6.4 导出设置（在设置中心配置）

1. 打开「设置 → 导出」标签。
2. 可配置：
   - 默认导出格式
   - 默认合并/分别导出偏好
   - 导出文件名规则（如 `{标题}_{日期}`）
3. 配置保存后，下次导出时自动使用这些默认值。

### 6.5 PDF 导出注意事项

- PDF 导出使用浏览器原生「打印为 PDF」功能。
- 弹出打印对话框后，目标打印机选择「另存为 PDF」。
- 建议在打印设置中：勾选「背景图形」以保留颜色样式。
- 移动端：iOS Safari 支持，Android Chrome 支持。

### 6.6 DOCX 导出注意事项

- DOCX 导出依赖 CDN 加载 `docx.js` 库，需要网络连接。
- 生成的 Word 文档保留标题层级、加粗、列表等格式。
- 表格格式在 DOCX 中完整保留。

## 7. 报告库管理

### 7.1 查看报告库

1. 点击左侧「报告库」导航菜单。
2. 右侧主区域显示所有已保存报告的卡片列表。
3. 默认按创建时间降序排列（最新在上）。

### 7.2 报告卡片信息

每张卡片显示：
- 报告标题
- 生成时使用的模型名称
- 创建时间（相对时间，如「3天前」）
- 标签列表（如有）
- 收藏状态（★）
- 操作按钮（查看 / 导出 / 删除）

### 7.3 搜索与筛选

| 功能 | 操作方法 |
|------|----------|
| 关键词搜索 | 在报告库顶部搜索框输入关键词，实时过滤 |
| 只看收藏 | 点击「★ 仅显示收藏」切换按钮 |
| 按模型筛选 | 点击「模型」下拉筛选框，选择目标模型 |
| 按标签筛选 | 点击标签筛选区域中的标签名 |

### 7.4 删除报告

**删除单份报告**：
1. 在报告卡片右侧点击删除图标（🗑）。
2. 出现内联确认提示「确定要删除吗？」。
3. 点击「确认」完成删除，页面无需刷新，列表立即更新。

**批量删除**：
1. 点击「多选」进入多选模式。
2. 勾选要删除的报告。
3. 点击底部「删除已选 (N)」按钮。
4. 出现内联确认提示，点击「确认批量删除」。
5. 所选报告全部删除，列表实时更新。

### 7.5 标签管理

**添加标签**：
1. 打开报告详情，点击标签区域「+ 添加标签」。
2. 输入标签名，按回车确认。
3. 支持多个标签。

**删除标签**：
1. 点击标签旁的 ✕ 图标即可移除。

## 8. 数据源管理

### 8.1 数据源用途

数据源是你提供给 AI 的参考网址列表。生成报告时，系统会将这些地址包含在 Prompt 中，指引 AI 参考相关内容。

### 8.2 添加数据源

1. 点击「数据源」导航进入数据源页面。
2. 点击右上角「+ 添加数据源」按钮。
3. 填写：
   - **URL**：完整网址（必填），如 `https://www.stats.gov.cn/sj/`
   - **描述**：该数据源的简要说明（选填）
   - **标签**：分类标签（选填）
4. 点击「添加」保存。

### 8.3 管理已有数据源

| 操作 | 步骤 |
|------|------|
| 编辑 | 点击数据源卡片的编辑图标（✏），修改后保存 |
| 删除 | 点击删除图标（🗑），确认后移除 |
| 启用/禁用 | 点击开关切换，禁用后生成时不包含该数据源 |
| 排序 | 拖动卡片左侧拖动手柄调整顺序 |

### 8.4 同步数据源

1. 选择数据源后，点击数据源页面顶部「同步」按钮。
2. 系统尝试抓取这些网址的页面摘要。
3. 同步完成后，摘要内容附加到下次生成的 Prompt 中。

> ⚠ **注意**：部分网站因跨域限制（CORS）可能无法同步，建议改用该网站的 API 地址或开放数据接口。

## 9. 设置中心

### 9.1 打开设置

- **方法**：点击左侧边栏最底部的 ⚙ 图标。
- **关闭**：点击弹窗右上角 ✕，或点击弹窗外部灰色遮罩层。

### 9.2 设置标签页总览

| 标签 | 内容 |
|------|------|
| 通用 | 语言、界面字体大小、时间格式等 |
| 模型 | API Key 配置、自定义模型管理、生成参数 |
| 导出 | 默认导出格式、文件名规则 |
| 权限 | 角色权限配置表 |
| 外观 | 主题颜色、暗色模式、侧栏宽度 |
| 数据 | 清除本地数据、导入/导出配置 |

### 9.3 通用设置

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 界面语言 | 目前支持中文（简体） | 中文 |
| 字体大小 | 正文字号（12-20px） | 14px |
| 时间显示 | 相对时间 / 绝对时间 | 相对时间 |
| 自动保存 | 生成完成后自动保存到报告库 | 关 |

### 9.4 导出设置

1. 在「导出」标签页：
2. **默认格式**：点击格式图标选中（高亮显示）即为默认。
3. **合并策略**（JSON / MD 批量导出时）：
   - 选「合并为一份」：批量导出时合并到单文件。
   - 选「分别导出」：批量导出时逐个生成文件。
4. 点击「保存」使设置生效。

### 9.5 数据管理（清除本地数据）

> ⚠ **此操作不可逆！请在操作前导出重要报告。**

**清除所有保存的报告**：
1. 进入「设置 → 数据」标签。
2. 找到「清除本地数据」区域。
3. 点击「清除所有报告」按钮。
4. 页面内弹出确认提示（非浏览器弹窗），显示「即将永久删除所有已保存报告，此操作不可撤销。」
5. 点击红色「确认清除」按钮执行删除。
6. 页面内出现绿色 Toast「数据已清除」，报告库立即清空（无需刷新）。
7. 如点击「取消」则不执行任何操作。

**清除模型配置**：
1. 在「数据」标签点击「清除模型配置」。
2. 确认后，所有 API Key 和自定义模型数据被清除。

## 10. 权限管理

### 10.1 角色体系说明

系统内置三个角色：

| 角色 | 说明 | 典型使用场景 |
|------|------|-------------|
| admin（管理员） | 最高权限，可访问所有功能 | 团队负责人、系统管理员 |
| editor（编辑） | 可生成、保存、导出，不可修改模型和权限 | 内容团队成员 |
| viewer（查看者） | 只能查看已保存报告 | 外部只读查阅者 |

### 10.2 切换当前角色

1. 在「设置 → 权限」标签页顶部，或左侧边栏用户信息区域。
2. 点击「角色」下拉选择框，选择目标角色。
3. 界面立即刷新，不可访问的功能自动隐藏。
4. 当前角色存储于 `atlas_role` localStorage。

> 💡 **团队使用建议**：每位成员在自己的浏览器中设置对应角色，无需共享账号。

### 10.3 自定义权限配置

权限矩阵允许为每个角色单独开关每项功能：

**查看权限表**：
1. 进入「设置 → 权限」标签。
2. 权限表格行为「功能模块」，列为「角色」（admin / editor / viewer）。
3. 单元格显示勾选框（✓）或禁止符（-）。

**修改单个权限**：
1. 找到目标功能行和角色列的交叉单元格。
2. 直接点击该单元格。
3. 状态在「允许 ✓」和「禁止 -」之间切换。
4. 修改立即生效，同步写入 `atlas_perm_config` localStorage。
5. 无需点击保存按钮。

**可配置的权限项目**：

| 权限 Key | 功能描述 |
|----------|----------|
| generate | 生成新报告 |
| save | 保存报告到报告库 |
| export | 导出报告 |
| template | 使用和管理模板 |
| library | 访问报告库 |
| sources | 查看数据源 |
| source_manage | 添加/编辑/删除数据源 |
| sync | 同步数据源内容 |
| model_config | 配置模型和 API Key |
| appearance | 修改主题外观 |

**重置为默认权限**：
1. 在权限标签页底部点击「重置为默认」按钮。
2. 所有权限恢复为系统预设（如上表默认值）。

## 12. AI 动态

### 12.1 功能介绍

左侧边栏中部的 AI 动态区域，每日自动从 Hacker News 抓取 AI / LLM 相关热门新闻，并翻译为中文，每 5 秒轮播切换。

### 12.2 查看新闻详情

1. 在滚动条中看到感兴趣的新闻时，点击标题文字。
2. 浏览器新标签页打开原始英文文章链接。
3. 原始来源显示在标题下方（如 `techcrunch.com`）。

### 12.3 新闻数据来源与更新

| 项目 | 说明 |
|------|------|
| 数据源 | Hacker News Algolia API（`search_by_date`） |
| 查询关键词 | `AI LLM OpenAI Claude Gemini GPT` |
| 筛选条件 | 点赞数 ≥ 3，包含外链的文章 |
| 翻译服务 | Google Translate 非官方接口 |
| 缓存策略 | 每天首次加载时获取，结果缓存到当天结束 |
| 缓存位置 | `atlas_ai_news_{YYYY-MM-DD}` localStorage |

### 12.4 新闻加载失败时

- 刷新页面重试。
- 新闻加载失败不影响报告生成功能。

## 13. 本地数据管理

### 13.1 数据存储位置

所有用户数据存储在浏览器 localStorage，无服务器数据库：

| localStorage Key | 存储内容 |
|-----------------|----------|
| `atlas_saved_reports` | 所有已保存报告 |
| `atlas_selected_model` | 当前选中的模型 |
| `atlas_custom_models` | 用户添加的自定义模型列表 |
| `atlas_builtin_keys` | 内置模型的 API Key |
| `atlas_builtin_urls` | 内置模型的自定义 Base URL |
| `atlas_hidden_builtins` | 已移除（隐藏）的内置模型 ID 列表 |
| `atlas_role` | 当前角色（admin/editor/viewer） |
| `atlas_perm_config` | 自定义权限矩阵配置 |
| `atlas_theme` | 主题色和暗色模式设置 |
| `atlas_gen_params` | 生成参数（temperature、max_tokens等） |
| `atlas_sources` | 数据源列表 |
| `atlas_ai_news_{date}` | AI新闻缓存（按日期） |

### 13.2 数据备份

**手动备份**：
1. 进入「报告库」→「多选」→「全选」。
2. 点击「导出已选」→ 选择 JSON 格式 → 「合并为一份」。
3. 下载的 JSON 文件包含所有报告的完整元数据，可后续导入恢复。

**自动备份**：
- 可在「设置 → 数据」中开启「每天自动备份」，系统每日首次访问时触发 JSON 下载。

### 13.3 数据恢复（导入 JSON 备份）

1. 进入「设置 → 数据」→「导入备份」。
2. 点击「选择文件」，上传之前导出的 JSON 文件。
3. 系统解析文件，显示「发现 N 份报告」提示。
4. 选择导入模式：
   - **合并**：将备份中的报告追加到现有报告库（ID 冲突时跳过）。
   - **覆盖**：清除现有报告库，完全恢复为备份内容。
5. 点击「开始导入」，导入完成后报告库立即更新。

### 13.4 跨设备/跨浏览器同步

由于数据存储在 localStorage，不同设备/浏览器之间的数据**不会自动同步**。

**手动迁移方法**：
1. 在原设备上导出 JSON 备份（见 13.2）。
2. 将 JSON 文件发送到新设备（邮件、云盘等）。
3. 在新设备浏览器打开应用，通过「导入备份」（见 13.3）恢复。

### 13.5 隐私说明

- 所有数据仅存储在**你的浏览器本地**，不上传至任何服务器。
- API Key 明文存储于 localStorage，建议：
  - 不在公共计算机或共享账户使用。
  - 定期在 API 提供商后台检查 Key 使用情况。
  - 离开前使用「设置 → 数据 → 清除模型配置」清除 Key。

## 14. 常见问题与排查

### Q1：点击生成按钮，输出的是咖啡报告，不是我输入的主题？

**原因**：当前选中的模型没有配置 API Key，应用处于演示模式。

**解决**：
1. 点击 ⚙ 设置 → 「模型」标签。
2. 找到当前选中模型，在 API Key 框中填入有效 Key。
3. 保存后重新生成。

---

### Q2：报告生成报错「400 Bad Request」或「max_tokens is too large」？

**原因**：「Max Tokens」参数设置过大，超过 API 提供商限制。

**解决**：
1. 进入「设置 → 模型」。
2. 将「Max Tokens」改为合理值，推荐 `4096`（最大支持 `131072`）。
3. 保存后重试。

---

### Q3：页面显示的版本/功能与描述不符，明明应该有新功能？

**原因**：浏览器缓存了旧版 HTML 文件。

**解决**：
1. 按 `Ctrl+Shift+R`（Mac：`Cmd+Shift+R`）强制刷新。
2. 或打开开发者工具（F12）→ 右键刷新按钮 → 「清除缓存并硬性重新加载」。
3. 如仍不更新：开发者工具 → Application → Storage → Clear Site Data。

---

### Q4：数据源同步失败？

**原因**：目标网站存在 CORS 跨域限制，浏览器直接请求被拒绝。

**解决方案（三选一）**：
1. 改用该网站提供的公开 API 地址（如 RSS 接口）。
2. 在补充要求中手动粘贴关键数据。
3. 使用 CORS 代理服务（需自行搭建，注意数据安全）。

---

### Q5：导出 DOCX 时文件内容为空或格式混乱？

**原因**：`docx.js` CDN 加载失败（网络问题）或 Markdown 包含不支持的语法。

**解决**：
1. 检查网络连接，重试。
2. 切换为 Markdown 格式导出后手动转换。
3. 在 Word 中打开 .md 文件（Word 新版支持 Markdown）。

---

### Q6：AI 动态区域一直显示空白/加载中？

**原因**：Hacker News API 或 Google Translate 接口被网络拦截（常见于中国大陆网络）。

**说明**：AI 动态为非核心功能，不影响报告生成。可通过 VPN 或代理解决。

---

### Q7：切换角色后功能没有正确隐藏/显示？

**原因**：权限配置缓存未及时刷新，或自定义权限配置中有异常值。

**解决**：
1. 点击页面空白处，等待 1 秒后再切换角色。
2. 如仍异常：「设置 → 权限 → 重置为默认权限」。

---

### Q8：LocalStorage 已满，无法保存报告？

**原因**：浏览器 localStorage 通常有 5-10MB 限制，存储大量长篇报告后可能耗尽。

**解决**：
1. 导出 JSON 备份（见 13.2）。
2. 删除不需要的旧报告。
3. 或清除 `atlas_saved_reports` 后重新导入精简版备份。
