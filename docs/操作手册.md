## 一、3 分钟快速上手

### Step 1：注册登录

1. 打开 [atlas-essay.vercel.app](https://atlas-essay.vercel.app)
2. 点击右上角「登录 / 注册」→ 填写邮箱 + 密码 → 完成注册
3. **未登录也可直接使用**（演示模式，输出固定示例报告）

### Step 2：配置 AI 模型

**个人用户：**
1. 头像 → 设置 → 模型 → 找到目标模型 → 填入 API Key → 保存

**团队用户：**
- 由 Admin 在团队共享密钥中统一配置，成员无需各自填写

### Step 3：生成第一份报告

1. 首页输入框填写报告主题（如「2025年中国新能源汽车市场分析」）
2. 点击「生成报告」或按 **Ctrl/Cmd + Enter**
3. 等待 15–60 秒，报告实时流式显示，自动保存

## 二、个人使用旅程

### 2.1 注册与登录

| 场景 | 操作 |
|------|------|
| 首次注册 | 填写邮箱 + 密码 → Supabase 验证 → 进入工作台 |
| 已有账号 | 填写邮箱 + 密码 → JWT 颁发 → 进入工作台 |
| 退出登录 | 头像 → 退出登录 |
| 演示模式 | 不登录直接使用，报告存本地 localStorage |

登录后建议：头像 → 用户资料 → 填写显示名称。

### 2.2 配置 AI 模型

**配置内置模型 Key：**

1. 设置 → 模型 → 找到目标模型卡片
2. 「API Key」框填入 Key（格式：`sk-xxx`）
3. 如使用中转服务，展开「高级」填写自定义 Base URL
4. 保存后，顶部模型选择器中该模型变为可用

**添加自定义模型（任意 OpenAI 兼容端点）：**

1. 设置 → 模型 → 「+ 添加自定义模型」
2. 填写：显示名称、Model ID、API Key、API Base URL
3. 添加后立即出现在选择列表

**切换当前模型：**

点击页面顶部左侧模型下拉框 → 选中目标模型 → 立即生效，刷新后保持。

**调节生成参数（生成模式预设）：**

| 模式 | Temperature | 适用场景 |
|------|------------|---------|
| 严谨 | 0.25 | 数据分析、财务报告 |
| 均衡（默认） | 0.45 | 大多数场景 |
| 探索 | 0.75 | 头脑风暴、创意报告 |

在设置 → 模型中也可手动精调 Temperature / Top-P / Frequency Penalty。

### 2.3 生成报告（标准模式）

1. 首页输入框填写主题
2. 工具栏配置（可选）：
   - **语气风格**：正式 / 分析 / 叙事 / 批判性 / 简洁
   - **目标字数**：500–10000 字
   - **数据源**：关联已添加的数据源（详见 [数据源管理](#数据源管理)）
   - **附件**：上传 xlsx / docx / pdf 等作为上下文
3. 点击「生成报告」
4. 生成完成后自动保存至报告库

**快速填充主题（模板）：**

首页下方有内置模板卡片（行业分析 / 竞品调研 / SWOT / 工作总结等），点击即填入 Prompt。设置中可创建自定义模板。

### 2.4 查看与编辑报告

**报告页面布局：**

- 主区域：报告正文，Markdown 渲染，含章节/图表/引文
- 右侧边注栏（Marginalia）：随章节滚动的注释和数据要点
- 底部追问区：以当前报告为上下文继续提问

**行内编辑：**

点击正文任意段落 → 变为可编辑文本框 → 修改后点击外部自动保存

**评分反馈：**

报告页顶部有好评 / 差评按钮。差评可选择原因（如「内容不准确」），原因自动累积到写作画像，影响下次生成质量。

**增量更新：**

报告页 → 「基于此更新」→ 用当前报告的章节结构 + 新主题重新生成，保持结构不变。

**章节精修：**

点击任意章节标题旁的精修按钮 → AI 对该章节单独重写，不影响其他章节。

### 2.5 导出报告

在报告查看页或报告库中点击「导出」：

| 格式 | 适用场景 |
|------|---------|
| PDF | 打印、归档、正式提交（浏览器打印，建议勾选「背景图形」） |
| DOCX | 需要在 Word 继续编辑（保留标题/列表/表格格式） |
| Markdown | 开发者、Obsidian、技术写作 |
| Notion | 直接粘贴至 Notion 新页面 |
| 分享链接 | 分享给他人查看（链接不含 API Key，安全） |

**批量导出：**

报告库 → 开启多选 → 勾选报告 → 选择格式 → 选择「合并为一份」或「分别导出」→ 执行

## 三、团队使用旅程

### 3.1 创建团队（Admin）

1. 登录 → 进入「团队」页面
2. 「创建团队」→ 填写团队名称
3. 创建者自动成为 admin

### 3.2 邀请成员

1. 团队页面 → 成员管理 → 「邀请成员」
2. 输入成员邮箱，指定角色

| 角色 | 权限 |
|------|------|
| admin | 全部：管理成员、配置密钥、生成、导出、删除 |
| editor | 生成报告、查看报告库、导出；不能管理成员和密钥 |
| viewer | 只读：查看团队共享报告库 |

成员登录后即可看到团队工作台。

### 3.3 配置团队共享密钥（Admin）

成员无需各自填写 Key，Admin 统一配置：

1. 团队页面 → 「共享密钥」→「添加密钥」
2. 选择供应商（Anthropic / OpenAI / Google / DeepSeek）
3. 填入 API Key → 保存
4. 密钥经 AES-256 加密存储于 Supabase，成员不可直接查看

**生成时自动使用团队密钥：**

成员点击生成时，系统自动通过 `/api/generate` 服务端代理调用 AI，使用团队共享密钥，成员本地无需任何配置。

### 3.4 批量导入历史资产（Admin）

**导入个人历史报告：**

团队页 → 批量导入 → 导入报告 → 系统读取本地 localStorage 中的历史报告 → 确认 → 批量写入团队 Supabase

**导入个人 API Key：**

团队页 → 批量导入 → 导入密钥 → 读取本地配置的 Key → 加密写入团队 api_keys 表

### 3.5 团队协作使用

- 成员生成的报告自动同步至团队共享库（Supabase reports 表）
- 全体成员可在「报告库 → 团队报告」标签查看
- Editor 可编辑/导出，Viewer 只读
- 删除和批量操作均受角色权限限制

## 四、高级功能

### 4.1 研究模式（Agentic Tool Use）

开启后，AI 在正式生成前先进行资料收集：

1. 工具栏开启「研究模式」开关
2. 执行顺序：
   - Tavily API 实时搜索相关资料
   - Jina Reader 抓取关键网页正文
   - 模型自主决策是否需要调用更多工具（web_search / fetch_url）
3. 所有资料注入 `<context>` 后开始生成报告
4. 研究轨迹写入报告元数据，可在统计面板查看

> 研究模式通常多花 30–120 秒，适合需要实时数据或行业资料的报告。

### 4.2 大纲先行

先确认报告结构，再开始生成内容：

1. 工具栏开启「大纲先行」开关
2. 点击生成 → AI 先输出章节大纲
3. 用户可：拖拽排序 / 重命名 / 删除 / 新增章节
4. 确认大纲 → 点击「开始生成正文」
5. 各章节独立并发生成，速度比顺序生成快 **3–5 倍**

### 4.3 模型 Benchmark（横评）

**历史排行榜（被动统计）：**

报告库 → STATS 面板 → 「按模型分布」和「评分分布」，基于历史生成数据自动汇总各模型好评率、均字数、均耗时。

**主动横评烤机：**

1. 报告库 → Benchmark 面板 → 输入测试主题
2. 选择参与对比的模型（2–4 个）
3. 「开始横评」→ 系统并行发送相同 Prompt 给所有选中模型
4. 生成完成后并排展示结果，可直接评分对比

### 4.4 后台生成（关标签页继续跑）

适合生成时间较长、不想一直开着页面的场景：

1. 点击「后台生成」按钮（需已配置团队共享密钥）
2. 任务推送至 Upstash QStash 队列
3. 可直接关闭标签页，服务端继续执行
4. 重新打开应用 → 轮询发现 `status=done` → 自动加载报告

### 4.5 MCP 工具接入

将外部 MCP Server 的工具纳入 Atlas 研究循环：

1. 设置 → 工具 → 配置 MCP Server 地址
2. Atlas 自动发现可用工具（JSON-RPC / SSE 协议，4 种连接模式）
3. 研究模式运行时，模型可调用 MCP 工具获取专有数据
4. 支持 OAuth 2.1 授权的 MCP Server（PKCE + 动态客户端注册）

## 五、数据管理

### 5.1 存储架构

| 场景 | 存储位置 | 说明 |
|------|---------|------|
| 未登录个人使用 | localStorage | 数据仅在当前浏览器，清除缓存即消失 |
| 登录个人使用 | localStorage + Supabase | 报告云端备份，跨设备可访问 |
| 团队使用 | Supabase | 报告/密钥均在云端，团队成员共享 |

### 5.2 备份与恢复

**导出 JSON 备份（全量备份）：**

报告库 → 多选 → 全选 → 导出 → JSON → 合并为一份 → 下载

**从 JSON 恢复：**

设置 → 数据 → 导入备份 → 选择 JSON 文件 → 选择合并（追加）或覆盖模式 → 导入

### 5.3 清除本地数据

设置 → 数据 → 清除本地报告 → 页面内确认 UI → 确认清除

> ⚠️ 此操作不可逆，请操作前先导出 JSON 备份。

### 5.4 跨设备同步

- **已登录**：报告自动同步 Supabase，任意设备登录同账号即可访问
- **未登录**：数据在 localStorage，不同设备不共享
- **迁移**：导出 JSON → 新设备导入，或直接登录同一账号

## 六、常见问题 FAQ

**Q：点击生成，输出的是咖啡报告，不是我输入的主题？**

→ 演示模式：当前模型无 API Key。设置 → 模型 → 配置目标模型的 API Key，或联系团队 Admin 确认共享密钥是否配置。

---

**Q：报告生成出现「400 Bad Request」或「max_tokens is too large」？**

→ Max Tokens 超过模型/供应商限制。设置 → 模型 → 将 Max Tokens 改为 4096（Atlas 已设硬性上限 131072）。

---

**Q：页面显示旧版内容，新功能看不到？**

→ 浏览器缓存旧 HTML。Ctrl/Cmd + Shift + R 强制刷新，或开发者工具 → 清除缓存并硬性重新加载。

---

**Q：数据源同步失败？**

→ 目标网站 CORS 限制。改用该网站的 API/RSS 接口，或手动粘贴关键内容到补充说明框。

---

**Q：研究模式生成很慢？**

→ 正常现象。研究模式需多次调用外部工具（Tavily/Jina/模型自主决策），通常多花 30–120 秒。急需快速出结果时关闭研究模式。

---

**Q：切换角色后功能没有正确隐藏/显示？**

→ 设置 → 权限 → 重置为默认权限，再重新选择角色。

---

**Q：localStorage 满了，无法保存报告？**

→ 浏览器 localStorage 通常限制 5–10MB。导出 JSON 备份后删除旧报告；或登录账号使用 Supabase 云端存储，不受 localStorage 限制。

---

**Q：团队成员看不到我的报告？**

→ 确认：① 你生成报告时处于登录状态（未登录的报告只存本地）；② 对方已加入同一团队并有对应查看权限（viewer 以上）。

---

**Q：关闭标签页后报告没有生成完？**

→ 普通流式生成关闭标签页会中断。需要关 Tab 继续生成，请使用「后台生成」模式（需团队共享密钥）。
