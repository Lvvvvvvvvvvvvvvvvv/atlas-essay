## 1. 认证与账户

> 基于 Supabase Auth，邮箱密码登录，JWT 云端会话，跨设备同步。

| 功能 | 说明 | 存储 | 状态 |
|------|------|------|------|
| 邮箱注册 | 填写邮箱+密码创建账户 | Supabase auth.users | ✅ |
| 邮箱登录 | 邮箱+密码登录，颁发 JWT Session | Supabase Session | ✅ |
| 退出登录 | 清除本地 Session | 本地 | ✅ |
| 用户资料 | 设置显示名称，头像首字母自动生成 | Supabase profiles | ✅ |
| JWT 自动刷新 | Supabase JS Client 自动维护 Token 有效期 | 内存 | ✅ |
| 服务端身份校验 | API Routes 通过 auth.js 中间件验证每个请求的 JWT | 服务端 | ✅ |
| 未登录演示模式 | 未登录可用，输出固定示例报告，不消耗真实 API | 内存 | ✅ |

## 9. Harness 工程能力（ETCLOVG+M 八层）

> 围绕模型调用构建的"外壳"工程，全部闭环于 v3.1.0。

| 层 | 全称 | 完成度 | 核心落地能力 |
|----|------|--------|-------------|
| C | Context 上下文 | ~90% | 三区 System Prompt（角色/结构/动态注入）· Jina/Tavily 注入 `<context>` |
| E | Execution 执行参数 | ~85% | 生成模式预设 · 按模型自动调参 · Temperature/Top-P/Penalty 暴露 |
| V | Verification 输出校验 | ~80% | 五项结构校验 · 截断检测 · 自动续写 · 好坏评分 · Warning Banner |
| L | Lifecycle 任务编排 | ~90% | 大纲先行 · 分节并行（3–5x）· 节点工作流 · 章节精修 |
| T | Tooling 工具接入 | ~92% | Agentic Tool Use · Tavily · Jina · HTTP MCP · OAuth 2.1 MCP |
| O | Observability 可观测 | ~85% | 报告元数据（model/mode/时间/tokens/研究轨迹/promptHash）· 统计面板 · A/B |
| G | Governance 权限治理 | ~92% | 角色客户端+服务端双重强制 · 成本粗估 · 每日软限制 · 链接安全 |
| M | Memory 记忆层 | ~85% | 写作画像（偏好/避免）· 实体记忆 · 评分反哺 · `<user_memory>` 注入 |
